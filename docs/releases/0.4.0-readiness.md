# 0.4.0 release readiness — 2026-09-05

Status: **not approved for release**. This is an implementation/evidence ledger,
not a substitute for the immutable-SHA release gates.

## Implemented in this stabilization change

- Separate private agent browser runtime roots (`GREPPY_WEB_RUNTIME_DIR`) from
  shared inference roots and model-owner locks. Explicit whole-runtime harness
  isolation via `GREPPY_RUNTIME_DIR` remains supported.
- Existing private daemon endpoints can be resolved from a write-confined
  client without chmod. Two subprocesses with different browser roots contend
  for the same model lock; the sandboxed-client regression passes on macOS.
- Resolve launcher symlinks before locating the bundled Web runtime; preserve
  explicit runtime overrides and existing rejection of symlinked dist members.
- Retain private startup stderr on failure; identify the selected executable,
  child exit status/readiness deadline, and log path in the error.
- Correct browser instructions: `session create`, `script save --file`,
  `dom html`; do not equate successful dispatch with verified DOM state.
- Signed app gains read-only `--fskit-status` using Apple's public FSClient API.
  Setup requires the native module to be enabled at the exact bundle path,
  rather than trusting pluginkit election alone. Old apps without the helper
  are identified as a mismatched bundle, not repeatedly sent to the toggle.

## Subsequent bash-smart defect correction

When the index writer owns the store, long command output previously fell back
to the complete original log after its verdict/diagnostics. This contradicted
the compact-output contract and duplicated diagnostic blocks. Folding now stays
active without an expansion pack: it points to the already retained raw spool
file instead of inventing an expand ID. Short output and child exit status are
unchanged. If a raw recovery path is unavailable, full output remains the safe
fallback.

Regression: hold a real index writer, execute a command producing 500 stdout and
500 stderr lines, assert compact delivery for both, and verify both retained
raw files byte-for-byte. All 11 bash-smart integration tests and 22 unit tests
pass, plus library Clippy and formatting. No CTOX files or jobs were changed.
This subsequent product change requires new exact-SHA gates; the earlier signed
bundle is diagnostic evidence only, not a final artifact for the new source.
